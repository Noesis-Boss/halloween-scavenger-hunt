# SpookHunt Mobile: Halloween Scavenger Hunt & QR Sign-in

Mobile-first Halloween scavenger hunt tracker with camera QR sign-in, clue verification, leaderboard standings, and admin completion alerts (Admin PIN: `1881`).

## Run

```sh
npm run dev
```

Open `http://localhost:3000` (set `PORT=3001` or `WEBHOOK_URL=https://...` if needed).

## Test

```sh
npm test
```
