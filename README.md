# SpookHunt Mobile: Halloween Scavenger Hunt & QR Sign-in

Mobile-first Halloween scavenger hunt tracker with camera QR sign-in, clue verification, leaderboard standings, and admin completion alerts (Admin PIN: `1881`).

## Run

```sh
npm run dev
```

Open `http://localhost:3000` (set `PORT=3001` or `WEBHOOK_URL=https://...` if needed).

## Test

```sh
npm test
```

## Roadmap

- **Theme Selection:** Support switching themes beyond Halloween (Birthday party, Christmas, Easter, 4th of July, pirate/treasure hunt, etc.) with custom color palettes, festive icons, and audio chimes.
- **Pre-Packaged Clue Packs:** Themed starter riddles and preset squads tailored to each celebration.
